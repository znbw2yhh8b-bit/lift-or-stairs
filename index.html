            About the data

            Lift status comes from the Île-de-France Mobilités open dataset État des ascenseurs. Station staff check lifts on their rounds and the feed updates about three times a day, so a lift can break after the last check.

            The full station list, with the lines at each station, comes from IDFM's dataset Gares et stations du réseau ferré. A station with no lift in the feed is marked “No lift”: expect stairs there. Metro line 14 has lifts at every station.

            Routes come from IDFM's journey planner on PRIM. Line colours in the station view are approximate.

            Connect to IDFM with your API key

            IDFM's lift feed refuses requests without an API key. Create a free account on PRIM, copy your API key from your account page, and paste it here. It is saved only in this browser.

            Leave the address empty to use IDFM's standard one. If PRIM's État des ascenseurs page shows a different API link, paste it here.
